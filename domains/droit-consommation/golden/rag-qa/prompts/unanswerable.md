Mode « sans réponse » : rédige une question plausible, sur le même thème que l'article, à laquelle le Code de la consommation ne répond pas. Par exemple, un détail que le code ne fixe pas (un prix précis, une marque, un délai d'un autre domaine du droit), ou une situation voisine que l'article ne couvre pas. La question doit rester crédible pour quelqu'un qui consulte le code. Explique dans `why_unanswerable` pourquoi le code ne répond pas. Ne donne aucun fait.
