Mode « sans réponse » : rédige une question plausible, sur le même thème que l'article, à laquelle le Code de la consommation ne répond pas. Par exemple, un détail que le code ne fixe pas (un prix précis, une marque), ou une situation voisine que l'article ne couvre pas. La question doit rester crédible pour quelqu'un qui consulte le code, et ne doit pas porter sur un autre code. Si tu penses qu'un autre article du Code de la consommation pourrait y répondre, choisis une autre question. Explique dans `why_unanswerable` pourquoi le code ne répond pas. Ne donne aucun fait.
